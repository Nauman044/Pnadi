GITHUB PAR LIVE KARNE KE STEPS (GitHub Pages)

1. github.com par login karo -> top right "+" -> "New repository".
2. Name likho: pandii-birthday  -> "Public" select karo -> "Create repository".
3. "uploading an existing file" par click karo.
4. Is zip ko extract karo, phir index.html file drag & drop karo (zip nahi, file upload karni hai).
5. Neeche "Commit changes" dabao.
6. Repository ki "Settings" -> left side "Pages".
7. "Branch" mein "main" aur folder "/ (root)" select karo -> "Save".
8. 1-2 minute baad link ban jayega:
   https://TUMHARA-USERNAME.github.io/pandii-birthday/
   Ye link apni dost ko bhej do.

Note: music ke liye gift par tap karna zaroori hai (browser ki rule).
